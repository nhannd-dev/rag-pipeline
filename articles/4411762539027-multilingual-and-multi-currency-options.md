#### Multi-Currency Options

OptiSigns supports payment in USD, CAD, GBP, EUR, and AUD
Just select your preferred payment currency on checkout.

#### Multi-Language Options

There may be some parts of the app that are not translated, or localized.
If you notice areas we can improve, please send us a screenshot and your suggestion on how to improve the translation to [support@optisigns.com](mailto:support@optisigns.com)

Currently:

- Portal app.optisigns.com: supports:
  - English
  - Deutsch (German)
  - Español (Spanish)
  - Français (French)
  - Português (Portuguese)
  - Svenska (Swedish)
  - Italiano (Italian)
  - Nederlands (Dutch)
  - 日本語 (Japanese)

You can set language at your profile level (only affects yourself), or at the account level that will set the chosen language as the default for all users in the account.
Each user can set their preference regardless of account level preference.

To set the language for your profile go to:

<https://app.optisigns.com/app/s/personal-profile>

And select language

![Personal Profile Basic Info form with the Language list open, showing nine languages.](https://support.optisigns.com/hc/article_attachments/55635941411347)

To set the language for your account go to:

<https://app.optisigns.com/app/s/preference-settings>

select language (this will apply to all users on your account unless they set their preference).

![Preferences General section with the account Language list open, showing nine languages.](https://support.optisigns.com/hc/article_attachments/55635933731475)

#### Apps & Widget Translations:

- These apps are translated as:
  - Meeting Room
  - Google/Outlook Calendar
  - Simple Calendar

You can set the languages of those apps quite easily. These apps contain significantly more language options than the portal.

![Simple Calendar app settings with its Language list open, showing world locales.](https://support.optisigns.com/hc/article_attachments/55635941417747)

- These Widgets are translated as:
- Weather
- Time
- Date
- Calendar

You can set the language for widgets in the widget settings.

![Designer Format Options for a Weather widget with the Language list open.](https://support.optisigns.com/hc/article_attachments/55635933733523)

Currently, we only have 5 languages in our Designer widget:

- English
- Deutsch (German)
- Español (Spanish)
- Français (French)
- Svenska (Swedish)
