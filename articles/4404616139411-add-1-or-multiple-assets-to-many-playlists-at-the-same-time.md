# Add 1 or multiple assets to many playlists at the same time

Article URL: https://support.optisigns.com/hc/en-us/articles/4404616139411-Add-1-or-multiple-assets-to-many-playlists-at-the-same-time
Last updated: 2026-09-10T08:31:46Z

Sometimes you just create new assets and want to add them to several playlists, you can do it quickly:

Click ... on the asset, then click Add to Playlists

![Asset menu open with Add to Playlists highlighted](https://support.optisigns.com/hc/article_attachments/55274574155539)

You can also select multiple assets and click Add to Playlist button.

![Three assets selected and the Add to Playlist button highlighted](https://support.optisigns.com/hc/article_attachments/55274574301843)

Then select all the playlists you want to add to and click Add to ... Playlists.

![Add to Playlists dialog with two playlists ticked](https://support.optisigns.com/hc/article_attachments/55274574370707)

The assets will be added to the end of the playlists.

That's it, you have added assets to many playlists at the same time.
