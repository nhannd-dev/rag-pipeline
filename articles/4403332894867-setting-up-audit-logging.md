# Setting Up Audit Logging

Article URL: https://support.optisigns.com/hc/en-us/articles/4403332894867-Setting-Up-Audit-Logging
Last updated: 2026-09-21T20:44:11Z

With the Pro Plus, Engage, or Enterprise Plan, you can enable our Audit Log feature. This will log who has made what changes to your account.

Here are some feature highlights:

- Audit Log data is kept for **2 years or 200K records which ever reached first** (if you need longer data retention, please contact [support@optisigns.com](mailto:support@optisigns.com), this will incur additional cost)
- User login (how user logged in via Google SSO, MS SSO or email, password)
- New, Update, Delete Screens
- New, Update. Delete Assets/Files
- New, Update. Delete Playlist
- New, Update. Delete Schedule
- New, Update, Delete, Folders, change folder security settings
- Update Personal Profile, change password
- New, Update, Invite, Delete Users, Team (who invites who, who updates who)
- Change to Account Preference
- Submit, approve, reject of approval requests
- You can filter, search, export data

## Enabling Audit Log

Go to your [account settings page](https://app.optisigns.com/app/s/preference-settings):

Click **Enable Audit Log**, then hit **Save Changes**.

![OptiSigns Preferences, General section, with the Enable Audit Log checkbox ticked and outlined in red.](https://support.optisigns.com/hc/article_attachments/55643100038291)

After that audit events will automatically be logged.

### To view, search, export Audit Log data:

Go to account settings & click Audit Log under Data & Monitoring, or go directly here: <https://app.optisigns.com/app/security-audit-logging> 

![OptiSigns settings sidebar with Audit Log outlined in red under the Data and Monitoring group.](https://support.optisigns.com/hc/article_attachments/55643088540051)

You will be taken to the Audit Log page. Here's how it looks:

![The Audit Log page listing entries with Log Time, Action, Description, Team and Detail columns.](https://support.optisigns.com/hc/article_attachments/55643100038931)

You can filter for certain data that you need.

For example here we filter for changes to playlist in last 7 days.

![Audit Log page with the Filters popover open showing Entity Type, Team and User fields and a Run button.](https://support.optisigns.com/hc/article_attachments/55643100039571)

You can also search.

For example here we are searching for all changes related to "Lobby" to find changes to any screens labeled or containing "Lobby".

![Audit Log search box containing Lobby, outlined in red, with the matching entry listed below.](https://support.optisigns.com/hc/article_attachments/55643088546451)

You can also export the data out to CSV, Excel or PDF:

![The Export menu open on the Audit Log page, outlined in red, offering CSV, Excel and PDF.](https://support.optisigns.com/hc/article_attachments/55643088548371)

#### That's it!

You have activated and learned how to use the Audit Log feature.
