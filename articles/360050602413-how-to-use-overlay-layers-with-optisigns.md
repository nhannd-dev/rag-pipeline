# How to Use Overlay layers with OptiSigns

Article URL: https://support.optisigns.com/hc/en-us/articles/360050602413-How-to-Use-Overlay-layers-with-OptiSigns
Last updated: 2026-09-10T21:51:12Z

With OptiSigns Split Screen, you can overlay items on top of each other.
In example below we overlay OptiSigns Logo and a QR Code on top of the screen.
As the content play, the logo keep staying on top.
This is particular useful if you want to overlay logo, QR Codes, but you can overlay any content.

![Split-screen menu board with the OptiSigns logo overlaid top-left and a QR code bottom-right.](https://support.optisigns.com/hc/article_attachments/360076448373)

To create overlay layer, use the Split Screen app. If you haven't use the Split Screen app before, you can read the [how to here.](https://support.optisigns.com/hc/en-us/articles/360026559573)

In Split Screen Editor, you just need to add 1 more zone by clicking the **Add Zone** button.
The move, resize the zone to the area you want.
For example below, we made a small Purple zone for our overlay logo.
Then set that zone to display the logo.

![The Add Zone button in the Split Screen editor, and the new zone overlapping the Main zone.](https://support.optisigns.com/hc/article_attachments/55294838131347)

You can bring the zone layer Forward, Backward, etc to set overlay layers by using these buttons. Simply right click the zone you want as an overlay to show these options.

![Right-click menu on the selected zone: Bring Forward, Bring to Front, Send Backward, Send to Back.](https://support.optisigns.com/hc/article_attachments/55294838132115)

Tips: use a transparent PNG image if you want to have transparent background.
Note: Transparent PNG background currently only work for Windows, Linux, Mac, Raspberry Pi. On Android & FireTV it will show as black background.
