# How to use Airtable with OptiSigns

Article URL: https://support.optisigns.com/hc/en-us/articles/9392587446675-How-to-use-Airtable-with-OptiSigns
Last updated: 2026-10-02T15:09:00Z

*Airtable* is a platform for building collaborative applications. You can display it on your Digital Signage screen with the OptiSigns.

You can view an example here:

![Example Airtable kanban board embedded on a screen, with Backlog, In progress and Complete columns](https://support.optisigns.com/hc/article_attachments/9392530973331)

## Let's jump in and get started:

First, you will need to have your screens set up and paired. For more information on how to do that, click [here](https://www.optisigns.com/blog/how-to-set-up-digital-signs-with-optisigns-and-amazon-fire-tv).

On the OptiSigns portal, go to **Files/Assets > Apps**, then find the Airtable app.

![Files/Assets tab and Apps button, with the Add App dialog searching Airtable and the Airtable tile highlighted](https://support.optisigns.com/hc/article_attachments/56024698714899)

Enter details for your Airtable:

![Airtable app settings form with Name, Embed Code and Update Interval (600 seconds) fields, and Save button](https://support.optisigns.com/hc/article_attachments/56024698717331)

- Name: for you to remember, you can use the same Airtable name.
- Embed Code: Paste your Embed Code in this field.
- Update Interval: Default is 600 seconds (10 minutes). This mean the app will refresh the link every 10 mins for any changes in your Airtable. If you have a lot of slides, you may want to change this interval to something longer.

Note: Here is how to get the Embed code from your Airtable. 
Click "**Share view**" button and click "**<>Embed this viewon your site**" 

![Airtable base with the Share view menu open and the Embed this view on your site option highlighted](https://support.optisigns.com/hc/article_attachments/9392485841299)

Then you can edit the width or height in the Embed code. Then Copy and Paste it the OptiSigns' Airtable app.

![Airtable Embed view page showing the iframe embed code to copy, with desktop and mobile previews](https://support.optisigns.com/hc/article_attachments/9392446643731)

Click **Save**.

## That's all! Congratulations!

You have created your Airtable app.
You can change it any time by click on it in the Files/Assets tab.

You can assign the newly created Airtable asset to your screen by going to Screens, click Edit screens and assign the wall to screens that you want.

You can put the Airtable app in a Playlist or Schedule too.
