# How to Use the Slack App

Article URL: https://support.optisigns.com/hc/en-us/articles/4407335862931-How-to-Use-the-Slack-App
Last updated: 2026-10-01T21:46:16Z

To use Slack app with any 3rd party app like OptiSigns you will need:

- To create a Slack workspace. See how to [here](https://slack.com/intl/en-vn/help/articles/206845317-Create-a-Slack-workspace).
- An OptiSigns [Standard plan or above](https://www.optisigns.com/pricing)

After that, you're ready to use it with OptiSigns.

Chat log view screenshot is below, you can view a live example [here](https://social-player.optisigns.com/slack/?asset_id=kD84rTsZzScadRTmj):

![Slack app on a screen in Chat Log View, showing channel messages and a shared food flyer image](https://support.optisigns.com/hc/article_attachments/4409649423635)

## Let's jump in and get started:

First, you will need to have your screens set up and paired. For more information on how to do that, click [here](https://www.optisigns.com/blog/how-to-set-up-digital-signs-with-optisigns-and-amazon-fire-tv).

Then log on to our portal: <http://app.optisigns.com/>

Within the OptiSigns portal, go to **Files/Assets > Apps**, then find the Slack app.

![Files/Assets page with the Files/Assets tab and the Apps button highlighted](https://support.optisigns.com/hc/article_attachments/56000057687187)

Click Slack:

![Add App dialog searched for Slack, with an arrow pointing to the Slack app](https://support.optisigns.com/hc/article_attachments/56000057690899)

Click "SIGN IN WITH SLACK" and sign in with your credentials.

![Slack app dialog with the Sign In With Slack button highlighted](https://support.optisigns.com/hc/article_attachments/56000057691923)

![OptiSigns Slack Integration page with an arrow pointing to the Add to Slack button](https://support.optisigns.com/hc/article_attachments/4408767274899)

Enter your Slack app information:

![Slack app settings: Name, Channels, Message Filter, Display Mode, Theme, Photo, Text Color and Font Size](https://support.optisigns.com/hc/article_attachments/56000051193747)

- Name: Name of your Slack Wall, this is the name of the wall in your asset list. It will **not** be displayed on your screens.
- Channels: Select list of channels you want to display.

  - **Important**: you can only set this one time during the creation of the asset, if you want to change this later, you'll need to delete the old asset and create a new one.
- Message Filter: Show all messages, pinned messages or only messages with @OptiSigns.

  - **Important**: you can only set this one time during the creation of the asset, if you want to change this later, you should delete the old asset and create a new one.
- Display Mode: Select [**Chat Log View**](https://social-player.optisigns.com/slack/?asset_id=kD84rTsZzScadRTmj) (real-time update), [**Social Kiosk View**](https://social-player.optisigns.com/slack/?asset_id=d6tDAiaYTm9m8uqtY) or [**Timeline View**](https://social-player.optisigns.com/slack/?asset_id=LTfKWyLMiwg66mDZa). Click on the links to see live example.
- Theme: Select Slack, Light or Dark Theme.

  - You can select a Photo and set Text Color for your Slack Theme.

![Photo and Text Color fields shown when Slack Theme is selected](https://support.optisigns.com/hc/article_attachments/56000057693459)

- You can also customize your background and text color if you select Custom.

![Theme set to Custom, showing Background Color and Text Color fields](https://support.optisigns.com/hc/article_attachments/56000051196691)

- Speed: (only available if you select Social Kiosk View or Timeline View as your Display Mode) Select how fast you want the wall to scroll or switch between Slack posts. You can also customize your speed if you select Custom.

![Speed set to Custom, with a slider from 1 to 20 marked Slow, Medium and Fast](https://support.optisigns.com/hc/article_attachments/56000051197331)

- Font Size: Set the font size for the Slack app.

You can click Advanced and set:

- Always show new posts: When toggled on, will always show every new post. If you want to change these settings, hit the gear for content moderation. You can read more about [content moderation feature here](https://support.optisigns.com/hc/en-us/articles/4403015887763).
- Moderation: This is an option for you to moderate your content (show, hide certain posts), default is "Always show new posts" meaning all new posts automatically show up, no review, approval needed.
- Filter Posts: By Time (e.g., last 30 days) or by last XX number of posts.
- Scrolling Strip Font Size: If you put the Slack app to a SplitScreen zone that is a scrolling strip, you can set how big you want the scrolling text to be.
- Continue Playing Content in Playlist: In the playlist, the Slack app plays 10 items in the 1st round, and it will start with item #11 in the 2nd round.

![Advanced section: Always show new posts, Filter Posts, Scrolling Strip Font Size, Continue Playing Content in Playlist](https://support.optisigns.com/hc/article_attachments/56000057702803)

Click **Save**.
After saving, you can preview the wall. It may take several seconds for the app to fetch posts and prepare your wall, so please be patient.

## How to send messages to OptiSigns from Slack:

You can select how to send messages to OptiSigns from Slack by setting Message Filters:

- Show All: send all messages from your Slack channels to the OptiSigns Slack app.
- Only Pinned Messages: only send pinned messages from your Slack channels to the OptiSigns Slack app.
- Only @OptiSigns Messages: only send messages with @OptiSigns in content from your Slack channels to OptiSigns Slack app. (We do not fetch other messages.)

If your Slack message has more than one image, we only fetch the first image to display.

### Limitations:

- Currently, bot messages in a Slack channel will not display.

## That's all! Congratulations!

You have created your Slack Wall.
You can change the wall any time by clicking on it in the Files/Assets tab.

You can assign the newly created wall to your screen by going to Screens, click Edit screens and assign the wall to screens that you want.

You can put the created Slack walls in a Playlist or Schedule too.
