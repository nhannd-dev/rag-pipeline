# How to Create a Scrolling Strip or Bar

Article URL: https://support.optisigns.com/hc/en-us/articles/360026559613-How-to-Create-a-Scrolling-Strip-or-Bar
Last updated: 2026-09-11T08:02:40Z

This article will guide you through how to create Scrolling Strip / Bar, that normally accompany a Split Screen design like below:

![A split-screen layout with a scrolling strip across the bottom of the screen](https://support.optisigns.com/hc/article_attachments/360041995973)

To achieve the screen layout like above, we first [create a Split Screen layout](https://support.optisigns.com/hc/en-us/articles/360026559573).
Then create Scrolling Strip to assign to the bottom or top part of the split screen.

To create a Scrolling Strip, first click Files/Assets -> Apps -> Scrolling Strip

![The Scrolling Strip app tile in the Add App dialog](https://support.optisigns.com/hc/article_attachments/55223936023187)

Enter a name, this name will be use in your Asset list.
Next select Type. It can be Weather, News, Facebook, Instagram, Twitter feeds etc.

![The Scrolling Strip dialog showing the Name and Type fields](https://support.optisigns.com/hc/article_attachments/55223936028051)

For Type = Text, enter your own text. Each item separated by a new line (Enter).

![The Text field of the Scrolling Strip dialog with three lines entered](https://support.optisigns.com/hc/article_attachments/55223933825171)

You can click Advanced and set:

- Show date: Display data on your Scrolling Strip
- Show time: Display time on your Scrolling Strip
- Theme: Select Light or Dark Theme. You can also customize your background color if you select Custom.

![Advanced settings: Show Date, Show Time and Theme](https://support.optisigns.com/hc/article_attachments/55223936030483)

- Speed: Select how fast you want the wall to scroll or switch between news items on the scroll bar.

![Advanced settings: the Speed slider and the Spacing dropdown](https://support.optisigns.com/hc/article_attachments/55223933826707)

- Spacing: Set how much space between each item.
- Font Size: Set the font size for the Scrolling Strip app.

After Saved, the Scrolling Strip will appear in your Asset list.

![The saved scrolling strip in the Files/Assets list](https://support.optisigns.com/hc/article_attachments/55223936031763)

You then can assign the scrolling strip to your split screen zone.
For your convenient, if you use one of our Split Screen Templates, we already label Zone name with "Scrolling Strip" and you just need to assign the newly create Scrolling Strip there.

![The Split Screen zone editor, with the Bottom Scrolling Strip zone set to the scrolling strip asset](https://support.optisigns.com/hc/article_attachments/55223933829651)
